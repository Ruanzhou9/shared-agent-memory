# 聊天记录存档（L0）

原始对话由各自的 agent 会话存档维护（不进本库）。

本目录用于存放关键的、值得为共享记忆保留的对话**摘要或会话日志指针**：

- 何时写：一段对话沉淀出清晰的可复用记忆后，记录"这条记忆来自哪次对话/哪个决定"，便于溯源。
- 只写一句话摘要 + 会话指针，**不复制原文**。
- **指针禁止使用机器绝对路径**（`/Users/...`、`C:\Users\...`）：换设备即失效，还会被
  `scripts/pre-push-check.sh` 判为隐私泄漏。请写相对路径或"日期 + 主题"，例如：
  `2026-10-13 记忆库协议升级讨论`。

本目录起始为空。
