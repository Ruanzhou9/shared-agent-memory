# 示例原子记忆（非记忆区）

本目录存放 schema **示例**，用于照格式抄写。它们**不是记忆**：

- 目录名以 `_` 开头，协议已声明 `_` 前缀与 `_examples/` **禁止注入**；
- 示例的 `priority` 一律为 `1`，即使被误读也不会进入会话上下文；
- 用完请按 `../\_template.md` 的格式写你自己的真实记忆，然后可以删掉本目录。

> v1.0 的教训：早期版本把示例放在 `atoms/` 根目录且 `priority: 7/8`（≥6 会自动注入），
> 新用户不删就会把**虚构偏好**当成自己的真实记忆注入每次会话。这里用目录 + priority 双保险。
